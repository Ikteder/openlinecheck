# Changelog

## v0.1.0 — 2026-11-11 (starter prototype)

- Basic dependency-free HTTP download/upload and HTTPS latency/jitter tests.
- CLI with quick/standard modes, optional diagnostics, JSON output and configurable endpoint.
- Tkinter GUI with one-click speed test and manual advanced diagnostics.
- Loopback-only by default test server with request caps and upload byte receipts.
- Offline tests using loopback server; CI configuration for Windows, macOS and Linux.
- Explicit limitations and local-agent implementation roadmap.

Not production-validated or tested on the owner's Windows hardware yet.
